# FlightInfo — התקנה / Installation

<div dir="rtl">

**הורדה ישירה (Android):** https://github.com/eldadgalker-dev/FlightInfo/releases/latest/download/FlightInfo.apk

<img src="docs/qr-install.png" alt="QR" width="180">

עמוד ההתקנה המלא: https://eldadgalker-dev.github.io/FlightInfo/

1. פתח את הקישור בטלפון ואשר את ההורדה. אם Chrome מציג "Dangerous download blocked" — ⋮ ← הורדות ← הקש על הקובץ ← "Download dangerous file" (או השתמש ב־Firefox / Obtainium).
2. פתח את `FlightInfo.apk` מההתרעה או מ"הורדות".
3. אשר ל־Android להתקין אפליקציות מהדפדפן (פעם אחת).
4. אם Play Protect חוסם — "פרטים נוספים" ← "התקן בכל מקרה".

עדכונים: באפליקציה, הגדרות ← עדכון האפליקציה. או [Obtainium](https://github.com/ImranR98/Obtainium) עם כתובת ה־repo.
